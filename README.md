# 🧸 Kids Cartoon Shorts — AI Automation

Produce **ONE high-quality, original kids-cartoon YouTube Short every day** —
funny Hindi stories with your own recurring characters, generated by a
multi-agent pipeline (story → dialogue → scenes → images → voice → video →
thumbnail → upload) and controllable entirely from a Streamlit dashboard.

> Quality over quantity: **one** great video a day, not ten mediocre ones.
> Original characters only — never copyrighted ones. Funny stories, never
> facts/documentaries.

The legacy "trending facts" pipeline (`main.py`) is kept intact; the kids system
is the new default (`generate_kids.py`).

---

## ✨ What it does

| Stage | How |
|---|---|
| **Plan → Story → Dialogue → Scene → Prompt** | Multi-agent content brain (Gemini, free tier) writes a funny, kid-safe Hindi story with your characters |
| **Characters** | Reusable original cast with fixed *appearance tokens + seed* → the same character looks the same in every shot and every video |
| **Images** | Pluggable backends: **ComfyUI / AUTOMATIC1111 → Gemini → gradient** fallback (never stalls) |
| **Voice** | Free `edge-tts` neural Hindi voices with per-word timing |
| **Video** | MoviePy kinetic render: Ken Burns motion, word-by-word captions, hook, CTA |
| **Upload** | YouTube Data API v3; **manual anytime**, **automatic ≤ once / 24h** |
| **Dashboard** | Streamlit control center — characters, generation, scheduler, uploads |
| **Storage** | SQLite by default, or **Supabase/Postgres** (persistent, shared PC↔cloud) |

---

## ⚙️ Requirements

- **Python 3.12** (strongly recommended). On 3.14 the heavy media stack
  (MoviePy/NumPy/Torch) has no wheels yet — content generation works, but
  rendering won't.
- **ffmpeg** on your PATH (for video rendering).
- *(Optional)* **ComfyUI** for local cartoon image generation. Without it, the
  free **Gemini** image API is used automatically.
- A **Gemini API key** (free) — https://aistudio.google.com/apikey
- *(For uploads)* a YouTube OAuth client + refresh token.

## 🚀 Setup

```bash
git clone https://github.com/Ajain0311/PyGenerater.git
cd PyGenerater

# Use Python 3.12
py -3.12 -m venv .venv
.venv\Scripts\activate            # Windows (PowerShell: .venv\Scripts\Activate.ps1)
# source .venv/bin/activate       # Linux/Mac

pip install -r requirements.txt
```

**Install ffmpeg:** `winget install Gyan.FFmpeg` (Windows) · `sudo apt install ffmpeg` (Linux) · `brew install ffmpeg` (Mac).

### Configure `.env`

Copy `.env.example` → `.env` and fill in:

```env
# Gemini (free) — get keys at https://aistudio.google.com/apikey
GEMINI_API_KEY=...
GEMINI_API_KEY_2=...           # optional extras for quota rotation

# Database — leave blank for local SQLite, or use Supabase/Postgres for
# persistent state shared between your PC and the cloud dashboard:
DATABASE_URL=postgresql+psycopg2://USER:PASS@HOST:5432/postgres?sslmode=require

# Kids content
KIDS_LANGUAGE=hi
YOUTUBE_MADE_FOR_KIDS=true

# YouTube upload (see below)
YOUTUBE_CLIENT_ID=
YOUTUBE_CLIENT_SECRET=
YOUTUBE_REFRESH_TOKEN=
```

> `.env` and `secrets/` are git-ignored — never commit real keys.

### Seed your characters

```bash
python scripts/seed_characters.py     # adds Chintu, Gappu, Rani (edit freely in the dashboard)
```

### YouTube auth (only needed for uploading)

```bash
python scripts/setup_youtube_auth.py  # opens a browser; prints a refresh token (1//0…)
```
Paste the refresh token into `.env` as `YOUTUBE_REFRESH_TOKEN`.

## 🎬 Generate a video

```bash
python generate_kids.py --dry-run        # story only (no media) — cheapest sanity check
python generate_kids.py --skip-upload    # full render, no upload
python generate_kids.py                   # full pipeline (manual upload, no 24h gate)
python generate_kids.py --category magic  # force a category
python generate_kids.py --resume <uid>           # continue a crashed run
python generate_kids.py --regenerate RENDER --run <uid>   # redo one step
```

Output: `generated/videos/<slug>.mp4`, thumbnail, and a DB record. Every step is
persisted, so a crashed run resumes instead of restarting.

## ⏱️ Automatic uploads (the 24h rule)

- **Manual** uploads (dashboard, or `generate_kids.py` without `--auto`) are
  **always allowed** — no time limit.
- **Automatic** uploads happen **at most once every 24h**, measured from the last
  *successful automatic* upload. Manual uploads never reset this timer.

Run automation either way:

```bash
# Option A — Windows Task Scheduler: run this every few hours; the gate self-limits
python generate_kids.py --auto

# Option B — built-in daemon (checks hourly, generates only when due)
python run_scheduler.py
```

The dashboard shows last manual / last auto / next auto / countdown + an
Enable/Disable toggle.

```bash
streamlit run dashboard/app.py
```

import/export your cast), **Create Video**, **Automation** (auto-upload scheduler

> The dashboard can run locally or on Streamlit Cloud, but **video generation
> must run on your PC** (Streamlit Cloud has no GPU/ffmpeg and an ephemeral disk).
> Point both at the same `DATABASE_URL` to share state.

## 🎨 Local image generation (optional, for fully-free cartoons)

1. Install **ComfyUI** and a cartoon-friendly SD checkpoint (SD 1.5 / SDXL-Turbo;
   FLUX needs a strong GPU).
2. Start ComfyUI (default `http://127.0.0.1:8188`).
3. In `.env`: `IMAGE_BACKEND=auto`, `COMFYUI_URL=...`, `SD_MODEL=<checkpoint name>`.

No GPU? Leave `IMAGE_BACKEND=auto` — it falls back to the free Gemini image API,
then to gradient placeholders, so a run never fails.

---

## 🗄️ Database / Supabase

- Blank `DATABASE_URL` → local SQLite at `data/app.db`.
- Set `DATABASE_URL` → Postgres/Supabase; tables are created automatically on
  first connect. Use the **IPv4 session pooler** host for Supabase
  (`aws-0-<region>.pooler.supabase.com:5432`) and `sslmode=require`.

---

## 🛡️ Content rules (enforced in code)

`src/content_policy.py` blocks copyrighted characters (Motu Patlu, Doraemon,
Disney, Pokémon, …) and unsafe/off-channel themes (violence, fear, "facts"). A
generation that violates these is rejected and re-rolled.

## 🔧 Troubleshooting

| Problem | Fix |
|---|---|
| `MoviePy`/`numpy` won't install | Use **Python 3.12**, not 3.14 |
| `ffmpeg not found` | Install ffmpeg, add to PATH |
| Images are plain gradients | Start ComfyUI, set `SD_MODEL`, or set a `GEMINI_API_KEY` |
| Postgres SSL error | Use the pooler host + `?sslmode=require` |
| Upload skipped | Auto gate not open yet (once/24h) — use a manual upload, or wait |
